# Examples

Install the package in editable mode from the repository root:

```shell
python -m pip install -e .
```

Run the window and navigation example, whose pages are intentionally empty:

```shell
python examples/navigation_view_example.py
```

Run the multi-tab `ModernWindow` example without a menu bar:

```shell
python examples/tab_view_example.py
```

The tab example supports adding, closing, selecting, and dragging tabs. `TabView`
also provides `Ctrl+T`, `Ctrl+W`, `Ctrl+Tab`, and `Ctrl+Shift+Tab` shortcuts.
